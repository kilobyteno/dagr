# Dagr

Dagr is a privacy-centric, self-hostable team chat platform. Run it on your own infrastructure with one Docker Compose command, keep files and search local, and optionally enable end-to-end encryption for direct messages.

## Why Dagr?

- **Self-host first:** one-command deploy with Postgres, Redis, and MinIO
- **No required SaaS:** cache, files, and search stay under your control
- **API versioned from day one:** everything under `/api/v1/*`
- **E2EE ready:** optional encryption for DMs, designed as an extension point

## Status

Early scaffold. The HTTP API supports health, public config, and auth. Channels, messaging, and richer client features are next.
