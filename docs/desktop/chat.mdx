# Chat

After you open a workspace, the middle of the window is the conversation.

## Channels

The **Channels** list shows public and private channels.

- Public channels are open to everyone in the workspace.
- Private channels are invite only (lock icon).

Choose **New channel** (plus next to Channels). Set a name, an optional topic, and tick **Make private** if it should stay invite only.

The **⋯** menu on a channel has **Channel settings** (name, topic, privacy, delete) and, for private channels, a place to add a member by email.

On a wide window, **Details** on the right lists **Members**. **Files** and **Links** are not available yet. Owners and admins can add Incoming Webhooks from **Settings**. See [Apps](/desktop/apps).

## Direct messages

**Direct messages** is under the channel list. Open a person from the list, or choose **Message** on their profile card.

## Send a message

Type in the box at the bottom. Enter sends. Shift+Enter starts a new line.

The toolbar above the box adds markdown (bold, italic, lists, links, and so on) and emoji.

Hover a message for reactions, **Copy message**, **Mark unread**, and (on your own messages) **Edit message** or **Delete message…**. Edited messages show **(edited)**.

Clickable `@handle` mentions notify that person. See [Notifications](/desktop/notifications).

Type `[[` to mention a Docs page. Clicking `[[slug]]` opens that page. See [Docs](/desktop/docs).

## Schedule a message

Next to **Send**, open **Schedule send**. Pick **Later today**, **Tomorrow morning**, **Monday morning**, or **Custom time…**.

The message waits until that time. You need a running worker on the server for scheduled sends to go out. If you only started the API, ask whoever hosts Dagr to run the worker, or see [Worker](/hosting/worker).

## Links

Addresses in a message can show a preview. GIFs play in the thread.

The first time you open a link on a new domain, Dagr asks **Open external link?** You can **Open once** or **Always trust**. Manage the list under [Preferences](/desktop/preferences).

## History on Cloud Free

On a Free Cloud workspace, older messages drop off after 90 days. A banner explains this. Upgrade to Pro for unlimited history. Messages already removed do not come back. See [Plans](/cloud/plans).
