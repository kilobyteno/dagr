# Notifications

The bell on the left rail opens **Notifications**. That inbox lists mentions, invites, and workspace activity. If you are signed into more than one account, it combines them.

Tabs: **All**, **Unread**, **Mentions**. **Mark all as read** clears the unread count.

When something new arrives and the app is in the background, your computer may show a system notification. The dock or taskbar badge follows the unread count.

If that channel or DM is already open and the window is focused, Dagr does not show a system notification and does not leave the conversation unread.

## How much you hear

Your account default is in **Edit profile → Default notifications**:

| Choice | Meaning |
| --- | --- |
| All messages | Notify you about every new message by default |
| Mentions only | Only when someone uses your `@handle` |
| Nothing | No message notifications by default |

A channel can be quieter than that, never louder. Open the channel, then **Details → Settings**:

| Choice | Meaning |
| --- | --- |
| All messages | Every new message in this channel |
| Mentions only | Only `@handle` mentions |
| Nothing | Silence this channel |

Changes save as soon as you pick them.

**Nothing** at the account level also stops desktop system alerts.
