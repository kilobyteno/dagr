# Quick start

This is the shortest path to a working Dagr on your machine.

## What you need

- [Docker](https://docs.docker.com/get-docker/) and Docker Compose
- [Node.js](https://nodejs.org/) 20 or newer and [pnpm](https://pnpm.io/) (desktop app)
- A [shadcnblocks](https://www.shadcnblocks.com) Pro API key (the desktop app pulls UI blocks from that registry)

Go 1.25 or newer is only required if you run the API outside Docker.

## 1. Clone the repository

```bash
git clone https://github.com/kilobyteno/dagr.git
cd dagr
```

## 2. Start the server

```bash
make compose-up
```

This starts Postgres, Redis, MinIO, runs migrations, and starts the API on `http://localhost:8080`.

Check that it is up:

```bash
curl -s http://localhost:8080/api/v1/health
```

You should see `{"status":"ok"}`.

## 3. Open the desktop app

```bash
# add SHADCNBLOCKS_API_KEY to web/.env (see web/.env.example)
make web-install
make web-dev
```

On the login screen choose **Self-hosted** and use `http://localhost:8080`. Create an account, then create a workspace. That seeds a `#general` channel.

A second window against the same server (useful for invites and DMs):

```bash
make web-dev-2
```

## 4. Stop

```bash
make compose-down
```

Data stays in Docker volumes until you remove them. See [Self-hosting](/hosting/self-hosting).
