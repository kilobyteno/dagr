# Quick start

## Prerequisites

- Go 1.24 or newer (for local API development)
- Docker and Docker Compose (for the full stack)

## One-command self-host

From the repository root:

```bash
make compose-up
```

This starts Postgres, Redis, MinIO, and the Dagr API.

Check the API:

```bash
curl -s http://localhost:8080/api/v1/health
```

Expected response:

```json
{"status":"ok"}
```

Stop the stack:

```bash
make compose-down
```

## Local API only

If dependencies are already running (or you only need the HTTP server):

```bash
make run
```

Or build binaries:

```bash
make build
./bin/dagr
```

Copy `deploy/.env.example` from the repository for environment defaults.

## Useful Make targets

| Target | Description |
| --- | --- |
| `make build` | Build server, worker, and migrate binaries into `bin/` |
| `make run` | Run the API locally |
| `make test` | Run Go tests |
| `make lint` | Run golangci-lint if installed, otherwise `go vet` |
| `make compose-up` | Build and start the full stack |
| `make compose-down` | Stop the stack |
| `make docs-preview` | Preview this documentation locally via docs.page |
