# Desktop app

Dagr is a desktop app for macOS and Windows. You sign in to a server, join workspaces, and chat in channels and direct messages.

Download the installer from the Dagr website. That site is the `website/` app in this repository until a public address is published. You can also run the app from source with [Quick start](/quickstart).

| Guide | What it covers |
| --- | --- |
| [Sign in](/desktop/sign-in) | Cloud or your own server, new accounts, email verification |
| [Workspaces](/desktop/workspaces) | Create a workspace, invite people, roles, settings |
| [Chat](/desktop/chat) | Channels, direct messages, sending and scheduling |
| [Docs](/desktop/docs) | Workspace markdown pages and `[[slug]]` mentions |
| [Notifications](/desktop/notifications) | Inbox, mention alerts, what you can silence |
| [Preferences](/desktop/preferences) | Profile, status, appearance, extra accounts |
| [Apps](/desktop/apps) | Incoming Webhooks and channel URLs |
| [Webhook payloads](/desktop/webhooks) | Native and Slack JSON |
