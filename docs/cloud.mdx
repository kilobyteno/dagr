# Dagr Cloud

Dagr Cloud is the hosted product. Kilobyte runs the server. You sign in from the desktop app with the **Cloud** tab.

If you run Dagr on your own machine or on Northflank, you are not on Cloud. Your server has no plans and never asks for payment. Use [Hosting](/hosting) instead.

| Guide | What it covers |
| --- | --- |
| [Plans](/cloud/plans) | Free and Pro, what you get, who counts as a seat |
| [Billing](/cloud/billing) | Upgrade, pay, cancel, and what happens at period end |

To start a Cloud account, open the desktop app and choose **Cloud** on [Sign in](/desktop/sign-in).
